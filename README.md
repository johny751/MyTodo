# 高效 ToDo 本地复刻版（0.9.2）

本项目根据 gxtodo 网页与高效 ToDo 7.1.2 APK 的界面观察、REA 静态分析独立实现。网页与 Android 共用任务模型，数据保存在各自设备，可通过坚果云 WebDAV 合并同步。

0.9.2 新增优化意见：Android 接入 Feedback Kit 1.2.0，网页和 Windows 提供独立文字意见及可互导备份。新子任务按点击添加时的当前北京时间安排，全天关闭、结束时间留空，分类仍沿用父任务。安装和使用见 [0.9.2 说明](docs/release-092-20261113/使用说明.md)。Android 保留番茄钟关联任务，以及通知栏暂停/继续；同时保留常驻待办状态条、倒计时/正计时、跨应用悬浮球、应用排除名单和自定义菜单。安装与权限说明见 [Android 使用说明](docs/android-focus-091-20261101/使用说明.md)，独立安卓发布包见 [Android 0.9.2 ZIP](发布/0.9.2/GxTodo-Android-0.9.2.zip)及[发布说明](发布/0.9.2/发布说明.md)。网页和 Windows 本版也更新为 0.9.2。

任务详情回车换行与独立保存按钮的变更见 [0.8.3 输入与保存说明](docs/release-v083.md)。

## 分发给其他用户

Android 当前发布版本为 [0.9.2](发布/0.9.2/发布说明.md)，网页和 Windows 原生程序发布版本为 [0.9.2](发布/0.9.2/发布说明.md)。各包只包含运行文件与使用说明；不会携带本机用户数据、同步账号或签名私钥。网页包内附 Node.js 运行环境，全新用户的业务数据为空，同步由使用者自行设置。

Windows 公开包默认使用当前用户目录；本机 dist/GxTodo-Native-0.9.2.exe 保留旧数据路径兼容行为。公开 EXE 通过 --public-release 单独构建，版本为 0.9.2。

## 启动和安装

- Windows 原生 C 版：双击 [dist/GxTodo-Native-0.9.2.exe](dist/GxTodo-Native-0.9.2.exe) 或桌面“高效 ToDo Windows 原生版”，无需网页服务或 Node.js。直接兼容现有 SQLite 与增量同步；“设置”现可配置数据库保存位置并迁移全部本地账号，原目录保留为备份，详见[保存位置说明](docs/windows-storage-location.md)；2026-10-24 已恢复象限标题整条新建、让任务详情自动替换并一次关闭、拖动柄悬停显示手形，三点菜单改为四色按钮卡片；内容区空白仍不新建，双击不最小化。已加宽拖动柄，EXE / 任务栏配有完整尺寸图标；万条任务的完整刷新中位耗时约 49 ms；[本次预览](docs/windows-row-actions-preview.md)。任务残留和页面白块修复、拖拽与菜单已通过 100% / 150% 缩放验收；[拖拽预览](docs/windows-drag-preview.md)。2026-10-22 已更新详情分区、原生控件、便签与分类卡片；[界面预览](docs/windows-ui-preview.md)。功能、实测资源和验收边界见 [原生版交互与验收说明](docs/windows-native.md)。

- 网页：双击 [start-local.cmd](start-local.cmd)，打开 http://127.0.0.1:4173 。已运行时复用服务。
- 停止网页服务：双击 [stop-local.cmd](stop-local.cmd)，数据保留。
- Android：安装 [dist/gxtodo-local-0.9.2.apk](dist/gxtodo-local-0.9.2.apk)，支持 Android 8.0 及以上。包名为 local.gxtodo.replica，可与原版并存。升级本地版直接覆盖安装，不必卸载。
- 命令行：Node.js 22.13+，执行 npm start。无第三方运行依赖，无需 npm install。

## SQLite 与六设备增量同步

0.8.0 面向 3 台电脑和 3 台 Android 手机：每个账号使用独立 SQLite 数据库，离线编辑写入持久化发件箱，经坚果云同步压缩后的变更批次。每个来源设备分别记录已读进度；并发提交、断线重试、删除标记与同字段冲突均有对应处理。详见 [六设备同步与升级说明](docs/sync-v2.md)。为其他网页或 Android APP 编写同步模块，请阅读 [通用 WebDAV 同步实现指南](docs/webdav-sync-implementation-guide.md)。

全部设备请升级后再使用同一云目录；首次新版同步会备份旧云端文件并阻止旧版继续整份覆盖。安卓仅在前台检查同步，进入后台或离线时暂停。

## 功能

- 网页、Android 支持最多 30 个独立本地账号。点击头像处“切换账号”可快速切换、创建或重命名。全新安装的所有账号从空白开始；已有账号 A 保留迁移数据；切换前保存任务与便签草稿。
- 每个账号的任务、便签、分类、设置、提醒记录和坚果云配置分别保存；不同账号可使用同一坚果云用户下的不同目录。Android 提醒和桌面小组件跟随当前账号。

- 手机端使用满宽四色四象限，隐藏常驻侧栏；左下角头像展开主菜单，底部切换时间轴及任务筛选。
- 宽屏网页（宽度大于 650 像素）点击任务直接打开详情，空象限可直接添加任务；窄屏点击任务区域先放大象限，再点任务打开详情。放大时保留四象限交界，另三个象限显示为两条窄边与一个角块；可以直接点击切换，或将任务拖进去。
- 网页和 Android 的象限标题整行可新建对应优先级的任务，最右侧“＋”提示同一操作；Windows 原生版的象限标题整条及“＋”均可新建，内容区空白单击和双击均不新建。放大时标题左箭头可恢复四象限。
- Android 返回键和网页浏览器后退按打开顺序逐层返回，详情有修改时自动保存；无效内容或保存失败会留在详情。首页连续两次返回（2 秒内）退出到后台。
- 每个象限独立滚动，放大、查看任务后返回恢复列表位置；总览保留长按跨象限拖拽，任务左滑菜单在放大后使用。
- 安卓主页面右滑打开左下角头像对应的主菜单。四象限上滑下一周期、下滑上一周期，跟随日/周/月筛选；列表先滚动，需从真实顶部向下或底部向上重新滑动才切换，也可在象限标题处滑动。轻点、拖拽、弹层和输入框有独立处理。
- 周视图顶部显示周一至周日范围，月视图顶部显示年月；前后箭头和“今天 / 本周 / 本月”随范围变化。点击顶部仍可选择日期或月份。

- 四象限任务、时间轴、日/周/月范围、完成状态和分类筛选。
- 宽屏网页的任务左侧保留完成圆圈，可直接勾选及撤销；手机列表隐藏完成圆圈，在详情顶部完成或恢复。
- 子任务输入支持回车换行；点击右侧“添加”按钮保存子任务，清空输入框并保持焦点。子任务支持拖动手柄调整同级顺序，也可用手柄的上下方向键；点击子任务进入完整详情，可继续添加嵌套子任务。顶部路径可回到任意父任务，关闭或返回逐层自动保存。
- 主任务和每层子任务共用开始/结束时间、全天、优先级、项目、标签、地点、备注、重复、提醒、分值、完成复盘、完成/恢复与删除。
- 完成某个子任务只改变自身状态；重复的下一次保留在原父任务下。搜索、分类时间轴、统计、提醒、导入导出与同步均包含嵌套任务。
- 任务详情的标题、备注、复盘、地点和子任务输入按 Enter 换行；项目和标签按 Enter 确认选择。点击独立“保存”按钮保存并保持详情打开；“关闭”保存后退出，“删除”删除当前任务。日期、时间和数值字段保持原格式，Enter 不会保存整条任务。
- 默认长按 3 秒拖拽排序或跨象限移动；也可直接拖动任务左侧拖动柄。左滑菜单可关闭，网页还可设置右滑完成；安卓右滑用于打开主菜单，长按时长可设置为 0.3–10 秒。
- 完成、恢复、删除、拖动、编辑后可以撤销，默认反悔时间 8 秒，可设置为 3–30 秒。多个操作独立计时；撤销不会覆盖后来对其他字段的修改。关闭或刷新应用后，当前撤销入口不保留。
- 每天、工作日、指定星期、每月、每年重复，可设置间隔和结束日期。每次完成后生成下一次，保留历史记录，下一次的子任务重置为未完成。月底和闰年按原始日期计算，不逐月漂移。
- 准时、提前 5/10/15/30/60 分钟、当天或提前 1/2/3 天上午 9 点、自定义时间提醒。支持 10 分钟后再提醒。
- 便签紧凑排列及悬浮菜单；项目总数、完成数、完成率；项目、标签、地点的完整任务时间轴。
- 全局搜索包含子任务、备注、复盘、便签及分类；空格分隔关键词按 AND 匹配。
- 个人统计：完成率、逾期任务、最近 7 天完成记录、四象限进度和已完成分值。
- JSON 导出、导入预览与合并；坚果云增量同步、条件上传及字段冲突处理。
- Android 桌面四象限小组件，可调整大小；显示每个象限前 3 项未完成任务及剩余数量，点击进入应用。

## 坚果云同步

详细步骤见 [多账号使用说明](docs/accounts.md)和[坚果云配置说明](docs/sync.md)。网页与 Android 在“设置 → 坚果云同步”中填写相同账号、第三方应用密码和目录，再分别保存设置、立即同步。

## 提醒与重复任务的使用方式

所有任务时间使用北京时间（Asia/Shanghai），手机当前系统时区不会改变任务时间含义。

网页默认提供页内提醒；在设置中点击“开启系统通知”可请求浏览器通知权限。请保持网页运行，关闭网页或电脑休眠期间不弹出提醒；再次打开时会显示未处理的到期提醒。

Android 在设置中开启系统通知和准时提醒权限，任务保存后交给系统闹钟。应用在后台时也可提醒；设备重启后会重新安排。没有准时提醒权限时使用系统非精确闹钟，可能延迟。系统强行停止应用、通知渠道关闭或手机厂商省电限制仍会影响送达，需要重新打开应用或调整系统设置。

重复任务采用“完成后生成下一次”，每次从前一次的计划日期推算；不会自动铺满未来日期。若任务已逾期多天，下一次也可能仍在过去。编辑某次任务影响该次和它之后新生成的任务，已生成的其他实例需单独编辑。删除一个实例不会自动删除整条历史链。撤销完成操作会同时撤回生成的下一次；如果下一次后来被编辑，会保留这些编辑。超过反悔时间后手动重新打开旧记录，会保留已生成的下一次，避免误删工作。

## 数据和备份

- 当前电脑的账号 A 数据：M:/dev/gxtodo-local/data/tasks.sqlite；其他账号：data/accounts/账号ID/tasks.sqlite；账号清单为 data/accounts.json。旧 state.json 原样保留为升级前备份。Windows 原生版可在“设置”中更改此根目录并迁移所有账号。其他没有旧数据目录的 Windows 电脑默认使用 %LOCALAPPDATA%/GxTodoLocal/data。
- Android：账号 A 在应用私有目录的 tasks.sqlite，其他账号在 accounts/账号ID/tasks.sqlite。旧 JSON 保留；系统文件选择器可导出/导入业务数据备份。
- 升级前网页数据已另存为 state.before-v070-时间戳.json；0.8.0 升级前另保存源码和账号目录完整副本；正式数据未替换成验收数据。
- 数据格式升级为版本 2，兼容导入版本 1 的旧备份；旧子任务的 ID、标题和完成状态保留。网页与 Android 请都升级到 0.8.0 后再同步。旧客户端会拒绝读取新版数据，避免丢失嵌套详情；请勿降级后覆盖备份。
- 导入时先显示条目数，确认后与现有数据合并；同一 ID 的冲突内容保留副本。导入不会导入设备的凭据和交互设置。
- 可用环境变量 GXTODO_DATA_DIR 指定数据目录，PORT 指定端口。支持任务与子任务合计最多 100,000 条、每条最多 100 个直接子任务、最多 64 层嵌套，业务数据导入/API 单次最大 64 MiB；增量批次目标小于 384 KiB，单文件解压保护上限 8 MiB。
- 不同账号的标签页固定绑定各自账号；同一账号多个窗口保存不同字段可合并，同一设备先后保存同一字段采用后一次保存。数据库同步会话互斥，其他窗口仍可编辑。
