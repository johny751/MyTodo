# 四象限待办 0.9.2 发布包

三个压缩包可分别分发，全部运行文件和对应使用说明都在包内。请按使用设备选择：

| 文件 | 适用环境 | 开始使用 |
| --- | --- | --- |
| GxTodo-Web-0.9.2-Windows-x64.zip | Windows 10/11 x64 + 现代浏览器；内置 Node.js | 完整解压后双击 start.cmd |
| GxTodo-Android-0.9.2.zip | Android 8.0+ | 解压后安装 APK |
| GxTodo-Windows-0.9.2-x64.zip | Windows 10/11 x64 原生程序 | 解压后双击 GxTodo-Native.exe |

每份压缩包首次使用从空白业务数据开始，由使用者创建任务、本地账号及同步配置。已有用户升级会保留原数据。发布包不含个人数据库、账号配置、同步凭据、签名私钥或测试数据。

网页版和 Windows 原生版默认分别保存到 %LOCALAPPDATA%\GxTodoWeb\data 与 %LOCALAPPDATA%\GxTodoLocal\data；Android 使用应用私有目录。需要同一份业务数据时，由各位用户设置自己的坚果云账号和相同同步目录。

本版 Android APK 使用与既有本地版相同的签名，支持覆盖升级。Windows 原生 EXE 未附加商业代码签名。请通过可信渠道分发；可在 PowerShell 中运行 Get-FileHash 文件名 -Algorithm SHA256，与 SHA256SUMS.txt 对照。

release-manifest.json 列出各个压缩包与内部文件的完整 SHA-256 校验值。

## 本版修改与验证

子任务按点击添加时的当前北京时间开始，不再继承父任务日期、全天或结束时间。Android接入优化意见模块1.2.0，网页与Windows同步增加独立意见记录及备份。

详细用法见 [0.9.2使用说明](../../docs/release-092-20261113/使用说明.md)，[验证记录](验证记录.json)。共享121项回归、Windows核心/详情/反馈检查、Android实际意见页面及SQLite/备份恢复验收通过；网页真实界面自动操作受浏览器工具故障限制，Windows反馈真实指针操作未执行。所有发布ZIP及内部文件的CRC和SHA-256已核对。
