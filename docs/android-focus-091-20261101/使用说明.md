# Android 0.9.1 使用说明

0.9.1 增加了计时任务关联，以及通知栏中的独立暂停 / 继续按钮。打开「Android 工具」，切换到「番茄 / 计时」即可使用；通知栏和悬浮球中的计时入口也可打开该页面。

## 关联任务

1. 在「本轮关联任务」区域点击「关联任务」。
2. 列表显示**当前账号**的任务，包含子任务与已完成任务，并标注任务状态。
3. 可输入标题关键词搜索。每次最多显示 **100 条结果**；结果较多时，使用更具体的关键词缩小范围。
4. 选中一项后点击「关联」。页面显示关联任务标题、所属账号及完成状态，通知中也会显示关联标题。

已经关联后，可点击「更换任务」重新选择，**运行或暂停期间都可更换**。点击「取消关联」后，仍可独立计时。暂停与「重置」都会保留所选任务；重置后，下一轮可继续使用该关联。

切换应用账号后，已有计时仍保留原账号的关联。重新打开选择列表会读取当前账号的任务；保存时会再次核对账号与任务，遇到账号切换或任务已删除会提示重新选择。

关联任务被删除后，已有计时继续保留。回到 Android 工具页面检查关联时，会显示「关联任务已删除」，可更换任务或取消关联。

## 开始、暂停与重置

- **倒计时**：默认 **25 分钟**，可设置 **1–180 分钟**。输入时长后，点击旁边的「设置」保存，或直接点击「开始」。到时显示「本轮已完成」，并在已获通知权限时发送完成提醒。
- **正计时**：选择「正计时」后点击「开始」，从零累计专注时间，没有预设结束时间。
- **暂停 / 继续**：暂停后保留本轮计时与关联信息，点击「继续」接着计时。离开页面或切换到其他应用，运行中的计时继续。
- **重置**：结束并清空当前一轮，保留所选任务及已累计的今日统计。重置后可修改时长、切换模式或更换关联。

「完成番茄」和「累计专注」按北京时间归属当天。只有完成倒计时才增加完成番茄数量；暂停与重置不会清除今日统计。

## 在通知栏控制计时

开启「Android 工具 → 设置 → 状态栏通知」后，紧凑通知与展开通知均提供独立的计时控制按钮：

| 计时状态 | 通知按钮 | 点击后的行为 |
| --- | --- | --- |
| 正在运行 | 暂停 | 暂停当前计时。 |
| 已暂停 | 继续 | 恢复当前计时。 |
| 已完成或已重置 | 隐藏控制按钮 | 可点击计时入口回到工具页面。 |

**点击计时数字打开计时页面，点击旁边的「暂停」或「继续」直接操作计时。** 按钮分别执行明确的暂停和继续命令。

暂停后通知继续保留，包括刚开始便立即暂停的情况。关联任务标题显示在通知中，倒计时完成提醒也包含关联标题。

关闭「状态栏通知」会关闭待办快捷条。计时或悬浮球仍在使用时，Android 要求保留简洁的后台通知；有活动计时的简洁通知同样提供暂停 / 继续动作。部分系统需展开通知才能看到标准动作按钮。

原有快捷入口继续可用：

| 入口 | 操作 |
| --- | --- |
| 待办 / 当日待办 | 打开今日待办视图。 |
| 完成 / 当日完成 | 打开已完成待办视图。 |
| ＋ / 添加 | 打开新增待办入口。 |
| O 显示 / O 隐藏 | 开启或隐藏悬浮球，首次开启需授权悬浮窗。 |
| 番茄钟 / 计时数字 | 打开「番茄 / 计时」。 |
| 设置 | 在展开通知中打开 Android 工具设置。 |

通知统计按当前账号、北京时间（Asia/Shanghai）计算。「当日待办」包含今天及更早计划的未完成任务，以及未设日期的任务；重复任务按其有效日期范围判断。「当日完成」按实际完成时间归属当天，与原计划日期无关。父任务和子任务分别计数，删除的任务不计入。

## 权限与悬浮球

在 Android 工具中按对应入口完成系统授权：

| 权限 / 设置 | 用途 |
| --- | --- |
| 通知权限（Android 13 及以上） | 显示通知栏快捷入口与完成提醒。也需确保系统没有单独关闭「当日待办状态条」或「番茄钟完成」通知类别。 |
| 显示在其他应用上层 | 显示悬浮球。授权后返回应用，再开启悬浮球。 |
| 使用情况访问 | 执行「选定应用位于前台时隐藏悬浮球」的规则。未授权时，普通悬浮球仍可使用。 |
| 准时提醒 / 闹钟和提醒（Android 12 及以上） | 在计时页点击「管理准时提醒权限」授权，用于安排设备休眠时的倒计时唤醒。未授权时，计时状态仍按实际经过时间计算，休眠中的完成通知可能被系统延后。 |

悬浮球可拖动调整位置。在设置中开启「贴边缩为小圆点」后，第一次点击小圆点只展开球，第二次点击展开后的球打开菜单；闲置约 6 秒会缩小。关闭此选项后，保留完整球形入口。可用「自定义菜单」选择快捷项目，用「选择应用」设置自动隐藏规则。

Android 安全授权页面上，系统可能临时隐藏悬浮球。不同手机的权限入口名称有所不同；若锁屏后提醒延后或后台工具停止，可在手机电池 / 后台管理中允许本应用后台运行，部分厂商还需开启自启动。强行停止应用后需重新打开，才能恢复后台服务与提醒。

## REDMI K80 Pro 与小米超级岛

针对 **REDMI K80 Pro、HyperOS 3.0.305.0WOMCNXM.C11**，小米提供官方超级岛能力，但**当前本地 APK 尚未接入官方超级岛服务，本版不保证上岛**。

按[小米官方超级岛接入文档](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2132)，开发者需要为在架应用启用服务，配置 AppId 与应用签名指纹，并通过场景审核。调试需使用设备白名单（有效 30 天、最多 10 台设备），正式使用还需获得正式权限。系统支持超级岛本身不能替代应用的这些接入条件。
