# Windows 原生版 · 交互与性能更新（2026-10-21）

双击桌面“高效 ToDo Windows 原生版”，或 dist/GxTodo-Native.exe。当前为 C、Win32、SQLite 的 Windows x64 单 EXE，不需要网页服务、浏览器、WebView 或 Node.js。EXE 约 1.01 MiB。

## 本轮完成

- 深色导航、浅色象限标题、圆形完成按钮、任务元信息、右侧详情、自适应工具栏；窄窗口可放大象限并切换其他象限。
- 虚拟列表按屏幕附近缓存 96 条实体，取消固定 500 条分页；四象限默认手动顺序，时间轴和按时间排序可通过顶部菜单选择。
- 单击任务进入详情，完成按钮切换状态；右键菜单、上下移动、拖动排序、跨象限移动、长按、左右滑动、列表边界切换日期。手势和排版的人工等效验证仍待实机检查。
- 任务详情自由文本 Enter 换行，项目和标签 Enter 确认选择；独立“保存”按钮保存当前详情。便签 Enter 换行、Ctrl+Enter 保存。Tab 导航时滚动到输入字段。关闭、返回和切换页面会保存有效草稿，连续子任务输入在离开时保存。
- 嵌套子任务、父任务路径、子任务单击进入/完成、同级排序；删除后可返回，避免已删除记录阻塞导航。

- 项目、地点、标签的创建/改名/删除；任务关联随分类变更。项目活动/归档筛选、分类任务数量及完成率、分类时间轴。详情直接输入新名称会建立分类。
- 本地账号新建、重命名、切换，独立数据库和云配置，重名及复用同步目录校验。
- 多个独立倒计时撤销入口；撤销只还原该操作，保留之后对其他字段的编辑。
- 跨任务、便签、分类的空格关键词 AND 搜索，兼容 NFKC 和大小写；搜索缓存仅重建变更记录，网页连接更新后也会失效重建。
- 统计页面包含完成率、逾期、分值、最近七天和四象限进度。
- 网络同步在独立线程运行，界面可继续编辑；前台自动补齐、后台暂停、失败退避。已实现分片快照创建和读取，保留冲突版本和删除历史。
- 运行期间显示非阻塞提醒卡片，可查看、10 分钟后提醒或关闭。

## 操作

顶部“⋯”包含四象限/时间轴、状态、日周月、排序、同步、导入导出；项目页面还可切换活动或归档项目。象限标题及空白处新建；任务左侧细点为拖动起点，或按住等待设置中的长按时间。右键菜单也可完成排序及象限移动。

快捷键：Ctrl+N 新建、Ctrl+F 搜索、Ctrl+Z 撤销（列表中）、Alt+← 返回、Alt+→ 前进、Space 完成/恢复、Enter 详情、Ctrl+↑/↓ 排序、Esc 逐层返回、F5 刷新。编辑框保留自己的文本撤销。

详情中的高级设置可展开编辑重复、提醒、分值和复盘；默认收起以减少滚动。新任务继承当前日期或分类，子任务继承父任务的日期、项目、地点和标签。

## 数据和云同步

直接兼容现有网页/安卓 0.8.1 的 SQLite 与增量同步协议。当前电脑默认 M:/dev/gxtodo-local/data；其他电脑默认 %LOCALAPPDATA%/GxTodoLocal/data，可用 GXTODO_DATA_DIR 或 --data-dir 指定。各本地账号使用独立 tasks.sqlite。

同步设置保存坚果云邮箱、第三方应用密码及独立目录。凭据使用 Windows DPAPI，与现有网页保护格式兼容。网络期间编辑使用另一数据库连接；同步租约防止同设备重复发送。账号切换和配置修改需等当前同步结束。关闭窗口时等待同步收尾。

新设备通过应用同步加入；已有 v2/manifest.json 可直接使用。未迁移的旧 state.json 需先用网页/安卓 0.8.1 同步迁移。快照采用分片 gzip、SHA-256 和 ETag 条件发布；同步时检测数据版本，编辑期间不会发布不一致快照。没有自动删除批次或墓碑。

## 验收

32 项核心自测、48 项高级操作回归、91 项现有项目测试通过。核心和高级自测使用独立数据库，包含真实表单保存、无变化保存、复杂规则往返、子任务草稿、返回路径、账号隔离、分类关联、排序、撤销和搜索失效。

真实坚果云独立测试目录完成 9 步联调：原生创建快照被网页读取、网页快照被原生读取、双向修改、并发冲突、选择版本、删除传播与最终字段一致。正式数据没有写入测试内容。

在正式业务数据的独立副本上检查最终窗口控件，包含四象限、筛选、任务和非阻塞提醒卡片；带新索引的副本可被网页客户端创建和修改。正式数据完整性通过。

稳定空闲采样（3,524 条任务和 20 条便签，自动同步关闭）：工作集约 27.34 MiB、私有内存约 7.11 MiB，10 秒 CPU 时间增量为零，GDI 38 / USER 69 稳定。启动索引构建、提醒初始化、编辑及同步仍会使用 CPU；该采样不是启动耗时或长期零 CPU 保证。

- dist/GxTodo-Native.exe --data-dir 测试目录 --advanced-test
