# 多账号使用说明（0.8.0）

> 0.8.0 已采用 SQLite 与六设备增量同步。账号对应关系和密码配置方式不变；数据位置、升级顺序与同步规则请先阅读 [新版说明](sync-v2.md)。

网页点击左侧头像“切换账号”；手机点击左下角头像展开菜单，再点“切换账号”。点击账号卡片即可切换，应用会记住上次使用的账号。账号名称可以修改，也可以创建更多空白账号，最多 30 个。

这是设备上的独立数据空间，无需注册。账号 A 承接升级前的全部本地数据；既有任务及分类保留在 A。账号 B 从空白开始。账号名称和清单分别保存在各设备，不会自动同步到其他设备。

## 网页与手机对应账号的同步

| 本地账号 | 建议坚果云目录 | 两端配置 |
| --- | --- | --- |
| 账号 A：原有数据 | GxTodo | 网页 A 和手机 A 使用相同坚果云用户名、目录 |
| 账号 B：新数据 | GxTodo-B | 网页 B 和手机 B 使用相同坚果云用户名、目录 |
| 自建账号 | 创建时指定，如 Work | 两端各建一个账号，使用相同用户名、目录 |

在所选账号的“设置 → 坚果云同步”中填写坚果云注册邮箱、第三方应用密码和目录，启用并保存，然后点击立即同步。应用密码需要在坚果云账户安全中创建；它不是网页登录密码。

一个坚果云用户可以用于多个本地账号，只需使用不同文件夹。应用会阻止本机两个账号绑定同一用户名下的同一目录。不同设备的本地账号 ID 和名称可以不同，对应关系由坚果云用户名与目录决定。修改已有账号的同步目录会重置该账号的云端接收进度，下次将现有记录版本和删除标记与所选目录重新合并。

## 切换时的行为

- 自动保存任务详情、已输入的子任务和便签草稿；校验或保存失败会留在原账号。
- 正在同步时暂不切换，完成后可重试。
- 切换后从首页开始，原账号的撤销入口与页面历史不带入新账号。
- 每个网页标签页固定绑定它打开时的账号。切换其他标签页不会改变这个标签页的读写归属；刷新后采用最近选择的账号。
- Android 的系统提醒与桌面小组件只展示当前账号，切换时重排闹钟并清除前一账号的通知。再次切回时会检查该账号未处理的到期提醒。
- 同一账号的多个网页窗口保存不同字段会合并；同一设备先后保存同字段采用后一次保存。跨设备真正并发的同字段修改保留为可处理的冲突。

## 数据和备份

网页数据根目录为 M:/dev/gxtodo-local/data。A 使用根目录的 tasks.sqlite 和原有同步配置，旧 state.json 保留为升级前备份；其他账号放在 accounts/账号ID/ 下。其他没有旧目录的 Windows 电脑默认使用 %LOCALAPPDATA%/GxTodoLocal/data。Android 使用同样的相对目录结构，保存在应用私有目录。

任务、便签、项目、标签、地点、交互设置、提醒记录、同步凭据、版本、发件箱与接收进度均按账号隔离。导入导出只针对当前账号。JSON 任务备份不包含账号清单和应用密码；完整迁移设备前请备份各账号的数据，并记下对应同步目录。

本地账号不提供登录密码或设备访问控制。它用于区分数据，不替代操作系统的用户账户和文件权限。
