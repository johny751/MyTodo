## 核心发现

Windows 的工作管理以十页共享 LISTBOX 和多按钮矩阵为主，状态/历史有原始枚举和JSON，当前页选择层次不足。番茄钟功能完整，但默认控件堆叠、计时视觉弱、当前任务/设置/历史缺少清晰区域。需要导航、列表详情、操作层级的整体调整。

Android 的原生番茄依赖纵向默认控件和弹窗列表；大量任务难以定位，父子关系缺少可视层次。当前48CSSpx与原生48dp边缘范围不等于全部屏幕位置的系统手势通过。需要搜索/折叠、触摸尺寸、状态/动作分区，并在系统手势和三按钮模式下验证。

Web 已具备响应式、焦点、减弱动画与多项数据保护。主要问题是追加CSS覆盖多、正文/标签偏小、20路由同权重、通用弹窗标题、行内多动作缺少主次。V2面板挂在settings路由，需要同时纳入布局设计，不能只美化主页面。

三端可统一：颜色语义、字段用语、状态和确认、按钮层级、空/错/加载状态、任务层级和工作关系。三端应区别：Windows的键盘和高密度主从布局；Android的48dp目标、IME和系统返回；Web的宽屏表格、响应式与语义DOM。
