# D4-09 可交互原型说明

打开交付包 prototypes/d4-09/index.html，可分别进入Windows、Android、Web设计。原型全部离线、Vanilla HTML/CSS/JS，无CDN；页面切换、菜单、弹窗、搜索、层级展开与编辑可实际体验，不是截图替代品。

Windows 13页，以四象限为默认首页，重点工作台、列表/详情、模板/实例、番茄与历史。Android 12页，重点计时、任务搜索和父子折叠、跨页抽屉、备注与图片反馈。Web20条路由，重点桌面工作管理、计时历史、详情及组合V2面板的设计映射。三份详细操作与选择器手册同目录保留。

所有原型只使用内存合成数据；刷新会恢复初始样例。保存/删除/计时是原型交互，不能证明业务持久化、SQLite、生命周期或生产服务。Android原型备份状态明确为演示，不创建真实备份。Web/Windows若导出演示快照，格式显式标为原型，不作产品恢复包。

## 建议体验路径

1. Windows：工作台 → 工作事项 → 选中详情 → 编辑与Ctrl+Enter → 项目 → 模板创建实例 → 暂停/继续 → 番茄开始/暂停/结束 → 历史。
2. Android：四象限 → 抽屉 → 番茄 → 关联任务 → 搜索“会议纪要”查看父链 → 清除搜索/展开子项 → 选择并保存 → 计时 → 记录。再查看工作台、流程实例、备注与反馈。
3. Web：工作事项表格 → 筛选与详情 → 修改备注/保存 → 模板实例 → 番茄及历史 → 设置的隔离服务设计面板。
4. 各端查看空态、错误、确认及草稿保护；缩小窗口观察布局，Tab和Esc检查键盘。

## 设计决策

采用浅色工作背景、青蓝主要动作和深色文字；四象限保留四色语义。以“项目归属—当前状态—下一步”形成连续阅读路径。桌面采用紧凑列表和详情侧栏，手机采用单列与弹层；原生平台遵循既有控件、系统返回和计时服务边界。

用户原先要求设计后审核，后追加“我要睡觉了,还是不用等我审核了，之后如果你有需要可以直接进入 UI 改造。”因此不再等待中间设计确认；完成云端原型观察后继续候选UI实施。最终统一验收仍需负责人评价视觉偏好、信息密度及真实设备体验，联系人/跟进/归档人工状态保持未知。
