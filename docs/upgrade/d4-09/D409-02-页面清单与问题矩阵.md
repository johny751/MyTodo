# D4-09 页面清单与问题矩阵

| 页面 | Windows | Android | Web | 共同整改/保留 |
|---|---|---|---|---|
| 四象限 | P1 原生首页布局、导航选中 | P1窄宽/抽屉、触摸 | P1横向空间 | 原拖动/排序/跨象限/缩放/菜单/自动完成全保留 |
| 工作台 | P0数据缺少层次 | P1单列优先动作 | P0今日队列+项目脉络 | 从“看数字”改为明确待处理与下一步；不改统计逻辑 |
| 工作事项列表/详情 | P0列表与按钮矩阵 | P0触摸信息层次 | P0表格+上下文详情 | 名称/状态/项目/流程/时间/备注完整，保留CRUD和草稿 |
| 项目列表/详情 | P0色值无色块 | P1项目进展可扫描 | P0关系与下一步 | 复用现有关系，不增Schema |

## 验证维度

原型：路由、菜单、弹窗、任务选择、折叠、搜索、空/错态、键盘；桌面1440与缩窗、手机360/412；合成数据只在原型内存。

集成：原D4-08所有测试及更早58/164等各套继续保留且分开计数；Windows真EXE的96/144DPI、键盘和数据重开；Android模拟器原生Activity/服务/计时/备份及新增任务搜索层级和两种系统导航模式；Web两套存储组合和原长文本/选区。实际结果另见交付测试矩阵。

未运行、未覆盖、人工未知必须逐项注明，不能将静态设计、浏览器模拟手势、模拟器或用户真机验收混称。
