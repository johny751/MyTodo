## 三端落地

Windows 使用原有 C/Win32 HWND、原控件 ID、SQLite 和业务处理函数。工作管理改为左导航、列表与只读详情、固定操作区域；番茄钟强化计时、关联任务、配置、历史与统计的层次；表单和反馈统一间距、字体与按钮，并保留长表单滚动。新增呈现 helper 不含模型、迁移或同步操作。主四象限继续沿用原交互。

Android 保留原候选 Activity、NativeTimerStore 和后台服务。番茄钟使用原生布局与只读进度环；搜索选择器从原任务仓库读取结果，显示父链、支持子任务折叠，选择只更新草稿，仍通过原保存设置操作生效。应用内容导航触发带扩大到 64 CSS px，原生系统手势排除段保持 48 dp × 200 dp；弹窗限制 x>22 的内容带接管，保留 x<=22 原边缘导航及任务草稿往返恢复，编辑输入、水平滚动和系统返回沿用原优先级。新增模态测试明确从 x56 的新增 48..64 带开始。共享页面使用与 Web 相同的呈现改造。

Web 保留现有页面事件、保存、任务拖动、计时、反馈和工作关系处理。宽屏使用列表与预览并列，窄屏明确切换列表/预览；预览选中状态只在内存保存。现有 V2 隔离服务沿用原存储键与服务接口，UI 布局更新不将工作事项等演示实体写入 V2 模型。
