### 3.2 番茄计时

窗口默认760×820、最小650×720逻辑像素，关闭为隐藏。界面包括计时状态、账号/任务、专注/休息、倒计时/正计时、分钟配置、八个操作按钮、北京时间汇总与 UTC 历史。按钮采用两行四列，控件与间距通过绝对布局计算。证据：`windows/d408-timer.c:116–179`。

状态为 idle/running/paused/completed/ended，阶段 focus/break，模式 countdown/countup；分钟为1–180整数。15秒及终止节点持久化，500ms刷新；单调时钟继续，重启/时钟不可信时保留检查点并暂停。结束、完成确认与重置语义各自独立，命令具有 receipt 与 expectedRevision，运行中不允许切换模式/账号。见 `d408-timer.c:21–38`、`:48–108`。视觉改造不得把“确认完成”合并为自动开始下一轮，也不得将隐藏窗口视作计时结束。

### 3.3 反馈

窗口默认1080×820、最小980×750逻辑像素；左侧268宽列表/搜索，右侧标题、类型、状态、正文与图片列表，底部八按钮两行四列。输入变化650ms自动保存；切换列表、关闭或应用退出均先保存，失败保持待保存状态。见 `windows/d408-feedback.c:54–77`、`:184–220`。

“提交”为本机候选记录/事件，不存在远程反馈服务。图片上限20个、单图10MiB，检查 PNG/JPEG/GIF/BMP 签名并保存实际字节与 hash；GDI+ 原生预览按窗口缩放。删除保存批次，撤销按原集合恢复，冲突时不覆盖。导入/导出包括历史与图片，恢复前写安全备份。见 `d408-feedback.c:79–129`、`:172–182`。本轮未新增反馈截图观察，因此反馈视觉结论限于布局源码。
