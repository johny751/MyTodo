## 共同边界

所有应用执行、构建、测试、SQLite 和可运行打包均在 GitHub Actions。页面设计、源码检查与自动化成功不替代用户实机验收。原业务/数据持久化/同步协议保持冻结；生产连接、迁移、稳定签名和覆盖升级没有获得新授权。完成云端验证和交付后停止，交由负责人统一审核。
