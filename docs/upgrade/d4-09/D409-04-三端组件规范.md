# D4-09 三端组件规范与实现映射

| 组件 | 共同语义 | Windows Win32 | Android | Web |
|---|---|---|---|---|
| 应用导航 | 个人效率/工作管理分组、当前页清晰 | 保留HWND/命令入口，侧向模块导航 | 顶栏菜单+抽屉，系统返回优先 | 持久侧栏，窄窗折叠 |
| 主要按钮 | 每区一个强调动作，动词命名 | 标准键盘/焦点语义，34px起 | 48dp触摸，圆角12 | 原生button，34–40px |
| 工作列表 | 项目/状态/下一步可扫描 | report list/control，行选择打开详情 | 单列信息行，48dp以上触摸 | 语义table/list，选中侧栏 |
| 详情/编辑 | 读取与编辑分离，完整正文 | 自适应分栏，保留所有控件ID与命令 | 单页/底部弹层，系统返回 | 边栏或dialog，Esc返回焦点 |
| 输入/下拉 | 标签始终可见，错误就地显示 | EDIT/COMBOBOX保留补全及Ctrl+Enter | EditText/原生选择，IME适配 | label/input/datalist或既有补全 |
| 状态徽标 | 文本+颜色 | GDI文本与浅色底 | TextView/shape | 语义span，不伪装按钮 |
| 番茄钟 | 当前关联、计时、主动作、历史 | 独立原生计时面板，历史列表 | 环形进度+底部动作+搜索任务 | 专注/历史双栏与筛选 |
| 任务关联 | 关键词、父子层级、选中反馈 | 保留现有任务候选逻辑 | 搜索过滤+父子折叠UI，不改关系 | 保留选择与持久化适配 |
| 菜单/弹窗 | 焦点管理、Esc/返回、安全确认 | 原生modal/menus | Dialog/系统Back | dialog/menu+aria |
| 备注/长文本 | 自动换行、选区可见、可滚动 | 多行EDIT，不截断读取值 | 可选择文本/IME可见 | overflow-wrap:anywhere、pre-wrap |
| 反馈图片 | 添加/预览/删除真实可用 | 既有原生能力保持 | 原Media/FeedbackKit保留 | 既有独立反馈能力 |
| 设置/版本 | 构建来源、复制、离线历史 | 真实构建身份 | versionName/code/git前5/编译时区 | 真实来源和存储说明 |

## 适配与验收

Windows 96/144 DPI，桌面与缩放；Android 360/412等宽度、手势/三按钮导航，原生Activity重建/后台/恢复原测试；Web360/412/桌面，键盘、菜单、选区、长文本。每项必须记录实际观察范围，浏览器模拟触摸不能写作Android系统手势验证。

原型和候选都应含加载/空态/错误/确认示例，但产品中的业务失败仍必须来自原服务返回，不由展示层吞掉。设计Token放在 prototypes/d4-09/tokens.css 与 tokens.json。原生映射允许系统控件保留平台特色，不能为了像素一致替换成熟业务。

## 文件所有权

root：设计文档、共享Token、原型入口、Actions与独立门禁、证据整合。
Windows代理：windows.html/css/js，Windows候选UI呈现及新增Windows独立D409测试。
Android代理：android.html/css/js，Android候选UI与导航呈现及新增Android独立D409测试。
Web代理：web.html/css/js，共享Web呈现层与新增Web独立D409测试。

正式代码改造从原型提交后开始。任何需要碰业务/持久化边界的变更先报告主Agent，不因UI目标自行扩大范围。
