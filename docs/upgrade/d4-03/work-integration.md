## 名称、ID 与删除

**FACT（静态代码证据）**：V2 任务继续保留 `project` 名称字段；候选关联使用独立 `projectId`。名称回退只适用于该名称在项目集合中唯一的情况。重名项目选择项显示 ID；编辑已存在的重名项目可保持原名称，不能因修改负责人而被强制改名。

**FACT（静态代码证据）**：项目名称表单和提交校验统一限制 100 字，匹配 `src/model.mjs` 的 V2 项目名 / 任务项目字段上限；先拒绝超长值，不能依赖截断后继续建立关联。云端用例包含 101 字名称拒绝后继续正常创建。

改名只更新明确绑定 ID 的任务，以及唯一名称且没有 ID 的任务。重名但没有 ID 的历史任务保持原值，不自动选一个项目。删除项目清除可确定的当前关联，并在事项、实例和跟进历史保留操作前关联。任务、事项、流程和往来不会随项目删除而重建。

**BLOCKER**：实际历史任务只有名称、且存在多个同名项目时，不能在生产环境自动建立 ID 关系；需真实数据只读预检授权和负责人映射策略。隔离体验不绕过这一限制。

## 模板版本与历史缺口

**FACT（静态代码证据）**：新建模板起始 v1，改变名称、说明或步骤后递增；模板启用状态独立于定义版本。实例拥有独立定义快照、运行步骤和操作历史，不从当前模板动态读取步骤。

新合成 fixture 的版本和快照来自已知 fixture 定义。已经保存的旧体验工作域不会因运行 `seed()` 被回填为“已知历史版本”。旧模板缺少版本时显示“未记录”，禁止新建实例；用户保存当前定义后建立候选 v1，操作前记录仍明确缺少历史版本。旧实例缺少快照时保留既有步骤，禁止删除关联模板；即使后来保存模板，也不会伪造旧实例快照。

**BLOCKER**：真实历史实例快照、模板版本关系及平台存储入口尚需各端正式接入证据，本浏览器候选不能代替生产历史验证。

## 原始附件契约

**FACT（静态代码证据）**：事项附件由用户明确选择隔离体验文件，读取 `arrayBuffer()`；保存原字节 base64、字节数、SHA-256、文件名、MIME、lastModified 和实际捕获时刻。不压缩、不转码、不读取任何用户数据库、不上传远端。

下载前重新解码并验证长度和 SHA-256；不匹配则拒绝生成下载 Blob。下载使用二进制类型，原字节不变。删除附件需明确点击确认，历史保留文件元数据和哈希；历史不会重复复制大段 base64。

**PROPOSAL（体验限制）**：每次最多三个文件、每个最多 1 MiB、每事项总量最多 3 MiB。此限制只用于独立 Demo，不能宣称为生产附件策略。

**UNVERIFIED / BLOCKER**：浏览器可能禁用或耗尽 localStorage；主仓库会降级内存。必须展示实际 `repo.persistence()` 状态，内存降级不算跨重启保存成功。原生多文件一致性快照、生产附件存储、Android 独立反馈图片字节和恢复仍由 A 线验证，不能从此体验附件测试推导通过。

## 统计日期口径

个人任务按开始日期筛选；事项按计划开始，缺失时截止 / 创建日期；项目按截止，缺失时创建日期；实例按创建日期；往来按沟通，缺失时创建日期。归档按归档日期筛选。时间段筛选时缺少有效日期的条目排除，并明确说明不补造日期。含 Z 或时区偏移的时刻转换为 Asia/Shanghai 日期；日期及无偏移的业务本地时间保留原日期，避免随云端宿主时区改变。任务完成趋势仅按已记录完成日期统计，包含跨北京时间午夜的合成边界用例。

**PROPOSAL**：这些筛选口径用于本候选页面讨论。正式生产分析口径仍需各端统一接入和负责人验收，不能替换原有个人统计实现。

## 云端回归准备

`runWorkCases` 保留原六项断言，并新增八项云端浏览器用例：

1. 项目负责人 / 成员、历史与 V2 扩展隔离。
2. 模板编辑、停用、复制和删除后实例快照不变，运行继续。
3. 事项日期拒绝、项目 / 实例关联、原始备注、完成时刻和历史原值。
4. 二进制附件字节 / 哈希 / lastModified、生成下载 Blob 的逐字节比较、篡改阻断、重载保存和删除；延迟附件完成不能关闭另一页面的未保存表单。
5. 沟通日期、下次跟进、关联、原字符串和完成历史。
6. 已完成内容归档 / 恢复与日期筛选后的独立计数。
7. 重名项目保持原名编辑、改名、删除均不误重绑未决历史任务。
8. 无版本模板的新建阻断、无快照实例的模板删除阻断、当前候选版本建立不伪造历史实例。

共十四项；最终以 Actions 报告逐项结果为准，禁止把此准备清单写成已经通过。

下载测试截获实际实现生成的 Blob 和下载名，验证输出字节，随后恢复浏览器方法；不把此测试当成真实 Android / Windows 文件保存能力验收。篡改样本只注入独立合成 `repo.demo`，失败后恢复原字节。

**UNVERIFIED**：本机仅进行了文件读取、编辑和静态人工复核。编译、测试总数、通过 / 失败数、原始日志、截图、产物 SHA 和 Actions 链接由主 Agent 云端报告统一附上。
