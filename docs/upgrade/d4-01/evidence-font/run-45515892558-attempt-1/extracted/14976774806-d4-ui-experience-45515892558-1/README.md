# MyTodo D4 可操作体验版

双击 mytodo-d4-01-demo.html，或运行 open-mytodo-demo.bat。无需安装、无需联网。

11 个页面可通过左侧导航访问；手机尺寸使用左上角菜单。任务、子任务、项目、事项、流程、往来、归档和统计操作使用合成数据。提醒显示于应用内提醒中心。

保存仅使用 mytodo-d4-01-demo-v1 专用演示空间；浏览器限制 file:// 保存时退回当前会话内存。设置页可导出合成修改或重置示例。

这是 UI 确认候选，不代表原生 Windows 整合或生产迁移通过。Android issue #1 保持开放。
