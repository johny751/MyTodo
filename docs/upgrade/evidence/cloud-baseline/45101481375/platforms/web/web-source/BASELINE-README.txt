Cloud baseline source package. Requires preinstalled Node >=22.13. No Node runtime, DPAPI helper, signing keys, real databases, credentials or user data are bundled. Use separate empty GXTODO_DATA_DIR and GXTODO_RUNTIME_DIR, then node launcher.cjs start --no-browser. Not an existing-data upgrade or a formal portable release. The suite tests a freshly built DPAPI helper separately with synthetic data.
