# 构建公开发布包

运行文件按显式清单加入压缩包，禁止递归复制工作区。正式发布输出在 发布/版本号，构建日志、隔离数据和解压验收保存在 windows/build，不会进入发布包。

1. 运行项目测试。
2. 构建 Android：npm run build:android。保留原签名密钥以支持覆盖升级，密钥不参与发布。
3. 单独构建 Windows 公开 EXE：node scripts/build-windows.mjs dist/GxTodo-Public-0.8.3.exe --public-release。公开构建关闭开发电脑 M 盘路径探测，版本资源取 package.json；个人使用的 dist/GxTodo-Native.exe 不需要覆盖。
4. 构建网页凭据助手：node scripts/build-credential-helper.mjs dist/WebCredentialHelper.exe。
5. 使用已经校验的官方 Node.js 24.19.0 win-x64/node.exe 运行 scripts/package-release.mjs。可通过 --node-runtime 指定运行环境，--windows-exe 指定 Windows 公开产物，--helper 指定凭据助手。默认 Node 许可和官方 SHA-256 列表保存在本目录，可通过 --node-license / --node-checksums 指定其他文件。
6. 打包脚本核对 Node 与 APK 校验值、压缩包内部清单，并生成 release-manifest.json 和 SHA256SUMS.txt。最后从压缩包解压到隔离目录，验证网页启动/停止、Windows 空白数据与 Android 安装升级。

网页使用的 Node.js 官方文件与许可来源：https://nodejs.org/dist/v24.19.0/ 和 https://github.com/nodejs/node/blob/v24.19.0/LICENSE 。必须保留附带运行环境的完整许可。

发布包中的安装与同步说明由本目录对应 Markdown 文件生成。{{VERSION}} 和 {{NODE_VERSION}} 由打包时替换。
