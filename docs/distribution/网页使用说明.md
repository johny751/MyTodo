# 四象限待办 · 本地网页版 {{VERSION}}

适用于 Windows 10/11 x64 与现代浏览器。包内已经包含 Node.js，不需要安装开发工具或执行 npm install。

## 启动和停止

1. 将整个压缩包解压到普通文件夹，不要在压缩软件内直接运行。
2. 双击 start.cmd，默认浏览器会打开本地网页。默认地址为 http://127.0.0.1:4173/；端口被占用时使用附近可用端口，启动窗口会显示实际地址。
3. 关闭浏览器页签不会停止本地服务，需要停止时双击 stop.cmd。
4. 再次启动会复用此安装目录已运行的同版本服务。升级前先停止旧包，再启动新包。

服务仅监听本机。数据保存在本地 SQLite，不依赖浏览器缓存；不要删除 src 或 runtime 文件夹。

数据目录：%LOCALAPPDATA%\GxTodoWeb\data

启动记录和日志：%LOCALAPPDATA%\GxTodoWeb\runtime

网页版与 Windows 原生版默认使用各自的数据目录。如需显示同一份业务数据，可自行配置相同的云同步目录。不要让两个程序同时打开同一个活动 SQLite 数据目录。

如需指定其他保存位置，在启动前设置 GXTODO_DATA_DIR；PORT 可设置端口，GXTODO_RUNTIME_DIR 可设置启动记录和日志目录。命令行示例：

~~~cmd
set "GXTODO_DATA_DIR=D:\MyTodoData"
start.cmd
~~~

网页系统提醒需要保持页面运行，并在设置中允许浏览器通知。

## 编辑与保存

任务详情中的标题、备注、复盘、地点和子任务内容按回车换行；项目和标签按回车确认选择。点击详情顶部“保存”按钮保存并保持打开。子任务点击“添加”后保存，关闭或返回时也会保存有效草稿。日期、时间和数值保持原格式，回车不会保存整条任务。

## 创建自己的数据与同步

首次使用没有演示任务、便签或分类。需要的内容由你自行创建；本地账号用于隔离数据，不是坚果云登录账号。

无需云账号即可离线使用。需要跨设备同步时：

1. 在你自己的坚果云账号中创建“第三方应用密码”。
2. 打开应用“设置 → 坚果云同步”，填写自己的登录邮箱、应用密码和同步目录，启用后保存。
3. 同一份数据的各台设备填写相同的坚果云账号和目录；不同份数据使用不同目录。目录支持 1–60 位字母、数字、下划线或短横线。
4. 点击“立即同步”，按提示继续到完成。首次连接会创建所需云目录并合并已有内容。

服务器地址为 https://dav.jianguoyun.com/dav/ 。同步传输压缩变更与快照，请不要用坚果云客户端直接同步正在使用的 SQLite 数据库文件。

同步在前台检查，后台收到的数据回到前台后再同步。任务、子任务、便签和分类参与同步；应用密码、设备权限和交互设置在各设备单独配置。发生并发冲突时，在同步设置中选择要保留的版本。

## 备份与升级

定期通过应用的 JSON 导出功能保存备份。导入会合并业务数据，不会带入别人的应用密码。建议所有设备升级到本版后再使用同一个云目录。

升级保留已经存在的本地内容；只有全新数据目录才从空白开始。升级前先导出备份。

## 0.9.2 新增功能

新子任务按点击添加时的当前北京时间开始，不继承父任务的日期、全天或结束时间；项目、标签、地点和象限仍沿用父任务。

设置中可打开“优化意见”，独立记录、查找、整理和备份改进想法。Android使用Feedback Kit 1.2.0，支持主动选择截图与独立ZIP备份/确认恢复。网页及Windows支持文字意见、待处理/已解决及互相导入的JSON备份，同编号按较新内容合并，同时间冲突保留副本；这些意见不参加任务同步。
