# 官网数据迁移

已登录的官网没有提供完整导出按钮时，本次通过浏览器实际使用的只读接口保存任务列表及详情，包含活动和归档项目、便签、标签、地点。没有保存 Cookie、密码或登录令牌。

转换工具只读取已保存的 JSON，不访问官网，也不直接改写运行中的本地数据：

```powershell
node scripts/import-official.mjs "<官网归档目录>" "<本地备份 JSON>"
```

输出：
- `converted-official.json`：官网数据转换为本地格式的独立备份。
- `merged-preview.json`：与本地现有数据合并后的预览。
- `import-ledger.json`：本地 ID 和原始任务、日程、日期的对应关系。
- `import-report.json`：数量、完整性校验和转换限制。

工具要求任务详情数量、项目任务数量、历史完成记录均与总表一致，否则中止。所有原始记录保存在归档目录；导入前另外备份本地状态。稳定的来源 ID 防止重复导入，同 ID 的本地编辑保留。

官网备注对应本地备注，总结对应完成复盘；日期按北京时间转换。循环任务保留规则，额外保存已有勾选记录对应的历史实例。未操作的历史自动重复日期不会全部展开。已经结束的循环任务在当日视图隐藏，仍可通过全部日期、搜索和历史日期查看。

官网没有返回任务创建时间和实际完成时间，转换时留空，避免伪造时间。地点坐标、原始秒级时间、来源 ID、参与者等暂时没有本地字段的内容保存在原始备份中。

迁移后的 JSON 可以通过本地网页“设置 → 从 JSON 备份导入”再次合并；回滚应使用迁移前备份完整恢复状态，而不是把旧备份再次合并进去。原始备份和含个人信息的转换文件应留在数据目录，不放入源码或版本库。

本次导入的 39 条过期提醒另存为本地数据目录中的 reminder-receipts.json。网页启动时读取收据，避免导入历史任务后重放旧提醒；修改提醒时间会使用新的收据标识。网页在浏览器存储不可用时仍保留当前会话的已提醒状态。
