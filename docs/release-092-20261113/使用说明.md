# 0.9.2 使用与升级说明

更新：2026-11-14，Asia/Shanghai。

本版优先更新 Android，并同步修正网页与 Windows 的子任务时间，增加各平台的优化意见入口。

## 安装升级

Android 安装 [gxtodo-local-0.9.2.apk](../../dist/gxtodo-local-0.9.2.apk)，包名仍为 local.gxtodo.replica，versionCode 为 15。沿用原签名，可直接覆盖安装，保留现有任务和账号。Windows 使用 [GxTodo-Native-0.9.2.exe](../../dist/GxTodo-Native-0.9.2.exe) 或 start-windows.cmd；网页重新启动服务后刷新。

## 子任务时间

在任意层级任务详情输入子任务，点击“添加”。新子任务的开始时间为点击添加的当前北京时间，精确到分钟；全天默认为关闭，结束时间留空。父任务即使设在未来、已经过期或是全天任务，也不会影响新子任务时间。

保存父任务发生延迟时，仍采用点击时刻。象限、项目、标签和地点继续沿用父任务，之后可在子任务详情单独修改。已有任务的时间不作批量修改。

## Android 优化意见

主菜单和设置中都能进入“优化意见”。使用正式 [Feedback Kit 1.2.0](../android-feedback-092-20261113/接入说明.md)，意见、草稿和主动选择的截图独立保存在本应用内。

- 查看和记录：打开意见列表或直接记录想法；可补充标题、正文、处理状态和截图，保存后再次打开仍保留。
- 查找整理：支持搜索、状态筛选、详情上一条/下一条及左右翻页，编辑和删除，整批删除后按模块提示撤销。
- 主动复制或分享：在意见页面选择操作，不会自动发送。
- 独立备份：在优化意见入口选择导出备份，通过系统文件选择器保存包含意见、草稿和截图的 ZIP。
- 恢复：先退出正在编辑的意见页面，在入口选择恢复备份并确认。恢复完整替换优化意见数据；取消选择不执行恢复，失败保留现有意见。恢复期间暂时不能打开意见编辑。
- 意见备份与任务 JSON 备份分别保存，优化意见不参与坚果云任务同步。

通知栏、悬浮球及番茄钟原有用法见 [Android 功能说明](../android-focus-091-20261101/使用说明.md)。

## 网页与 Windows

设置中打开“优化意见”；网页主菜单也有入口。可新建、编辑、查找，标记待处理或已解决，删除、主动复制和导入导出备份。

网页数据保存在当前浏览器。Windows 保存在稳定的 %LOCALAPPDATA%/GxTodoLocal/feedback/ideas.json，切换任务账号或迁移任务数据库不会改变意见位置。

两者使用同一种优化意见 JSON 备份，可互相导入。导入采用合并：同编号较新内容优先，同一时刻的不同内容保留独立副本，重复导入不会重复生成相同冲突副本。导入前会保留当前意见备份。网页可点击“导出导入前备份”，Windows 备份位于意见目录内。

网页和 Windows 的这一版提供文字意见与状态整理；截图、原生翻页及带截图 ZIP 备份由 Android 共享模块提供，Android 的 ZIP 与网页/Windows 的 JSON 分开使用。
