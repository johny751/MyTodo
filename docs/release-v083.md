# 0.8.3 任务详情输入与保存

2026-10-30：网页、Android 共享详情与 Windows 原生详情已更新。

- 标题、备注、复盘、地点和快速子任务的 Enter 输入换行，不提交整条任务。
- 项目、标签 Enter 确认选择，不保存整条任务。
- 日期、时间和数值控件保持格式，Enter 不提交整条任务。
- 独立“保存”按钮保存并保持详情打开；子任务使用独立“添加”按钮。
- 中文输入法候选确认不触发保存。关闭和返回仍保存有效草稿。

## 验证

项目 104 项自动测试全部通过，其中新增 8 项详情事件行为回归，覆盖普通输入、格式控件、项目/标签选择、IME、隐式 form submit、显式保存、失败保留草稿、地点清空和深层子任务。

Android 0.8.3 APK 构建和 v2/v3 签名校验通过，签名与 0.8.2 一致；20 项 APK 资产与当前源码逐字匹配。未进行本轮真机键盘实测。

## 使用更新

- 网页：刷新页面后使用新界面。
- Android：覆盖安装 gxtodo-local-0.8.3.apk。
- Windows：当前运行的旧窗口保持运行；关闭后从原“高效 ToDo Windows 原生版”桌面快捷方式或 start-windows.cmd 打开新版。当前新版个人程序为 dist/GxTodo-Native-0.8.3.exe，公开程序在发布压缩包中。
