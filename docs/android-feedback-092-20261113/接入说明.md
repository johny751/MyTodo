# Android 优化意见模块接入

宿主：四象限待办·本地版 0.9.2 / code 15。模块：Feedback Kit 1.2.0。
源发布目录：M:/dev/projects/android_shared_module/feedback/1.2.0。
AAR SHA-256：4c55a583a2641dfb68a90700a0759adec3e4ab1562dc5ccef7cbbc06e2896ade。

使用唯一 AAR 依赖 android/libs/feedback-kit-1.2.0.aar。保留共享包原内容，手工构建脚本合并其资源和非导出组件、替换宿主 applicationId、生成模块 R 类，用 Java 17 编译并由 D8 打包实际 classes.jar。宿主仍支持 Android 8.0（minSdk 26）。

MainActivity 的 GxNative.openFeedback() 和 newFeedbackIdea(source) 桥进入原生优化意见入口。FeedbackApplication 与 FeedbackToolsActivity 提供后台独立备份恢复、系统文档选择器和恢复确认。页面使用默认 DefaultFeedbackStorage，与任务、账号及同步表独立。

已存在意见页面时拒绝完整恢复，恢复期间禁止新编辑；恢复取消或失败保留数据。模块不自动联网、上传、截屏或收集设备标识。共享模块源目录未修改，宿主签名保留。

实际包组件、资源、DEX与签名核验见 [最终包核验](native-final-package-verification.json)。设备验证见 [UI与备份验证](native-ui-backup-verification.json)，旧 native-build-verification.json 为历史首轮构建记录。
